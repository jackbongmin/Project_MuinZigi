# [perf] 질문 문구 수정으로 자기 물건 오탐 감소 (v0 → v1 → v2)

## 문제
- 질문 세트 v0의 putting_in_bag은 "an item을 가방이나 주머니에 넣는가?"였음
- 손님이 **자기 폰을 자기 가방에 넣는 장면(N5)** 에서 0.84~0.86까지 올라가서, 진짜 상품을 넣는 장면(P1 0.70, P2 0.75)보다 높았음
- 상품 도난과 자기 물건 정리를 구분하지 못하면 미결제 의심 장면이 오탐으로 가득 참

## 측정 방법
- 데이터: AI 생성 영상 8편에서 1초당 1장씩 뽑은 프레임 109장 (P1~P3, N1~N5), 정답은 `2026-10-29_jev_영상_테스트.md`의 정답표(질문 세트를 바꾸기 전에 확정)
- 같은 실행에서 세트들을 같은 프레임에 연달아 보냄 (`JevFrameLiveTest`, 모델 `jev-1.14.0`)
- 판정: "예" 확률 0.5 이상이면 예, 정답이 "?"인 판단은 제외. 채점한 판단은 326개
- 측정 3회 (1회차: v0·v1, 2회차: v0·v1·v2). **v2는 1회만 측정함**
- **같은 입력도 확률이 매번 조금 흔들림**: v0 전체 일치가 어제 308개, 오늘 1회차 307개, 2회차 309개. 확률은 ±0.02~0.04 움직임

## Before / After
| 항목 | v0 | v1 | v2 |
|---|---|---|---|
| 전체 일치 (2회차) | 309 / 326 (94.8%) | 314 / 326 (96.3%) | 318 / 326 (97.5%) |
| 전체 일치 (1회차) | 307 | 315 | - |
| N5 putting_in_bag 오탐 | 7개 (최고 0.86) | **0개** (최고 0.34) | **0개** (최고 0.46) |
| N4 putting_in_bag 오탐 | 4개 (최고 0.80) | 5개 (최고 0.74) | **3개** (최고 0.69) |
| N4 holding_product 오탐 | 4개 | 5개 | 4개 |
| P2 7초 putting_in_bag (정답 예) | 0.75 | 0.46~0.52 (1회차 0.49) | 0.51 |
| P1 putting_in_bag 최고 | 0.70 | 0.69 | 0.50 |

- N5의 높은 확률이 사라지고 전체 일치율도 올랐지만, **진짜 넣는 장면의 확률도 같이 낮아짐** (표 아래 해석 참고)

## 변경 내용
- `QuestionSetV1`: holding_product와 putting_in_bag에 "진열대에서 가져온 매장 상품" 조건과 개인 물건 제외 문장을 넣음
- `QuestionSetV2`: v1의 "진열대에서 가져온" 조건은 빼고, putting_in_bag에 "폰·지갑 같은 개인 물건은 해당하지 않음" 문장만 남김. holding_product는 v0 문장에 "(쇼핑백, 폰, 지갑 제외)"만 추가
- person, paying은 세 세트 모두 같음
- `JevFrameLiveTest`는 세트들을 한 번에 돌려 질문 문장만 다른 조건으로 비교하도록 변경

## 해석
- **자기 물건 제외 문장이 효과가 있었음.** v1, v2 모두 N5 오탐이 사라짐. "진열대에서 가져온"이라는 조건이 없어도(v2) 같은 효과가 나옴
- **그러나 진짜 넣는 장면도 같이 눌림.** P2 7초가 0.75에서 0.5 안팎으로, P1 최고가 0.70에서 0.50으로 내려감
  - v1, v2의 P2 7초는 기준선 0.5 바로 위아래(0.46, 0.49, 0.51, 0.52)에서 실행마다 뒤집힘 → 이 값으로는 놓칠지 잡을지 안정적으로 정할 수 없음
  - "제외 문장"이 자기 물건뿐 아니라 가방·주머니에 넣는 동작 전체를 조심스럽게 만드는 것으로 추정
- **진짜 장면과 오탐의 확률이 여전히 겹침.** v2에서도 오탐 N4 최고 0.69가 진짜 장면 P2 0.51보다 높음 → 기준선을 어디로 잡아도 둘을 가르지 못함
- v2는 숫자가 가장 좋지만(전체 일치 97.5%) 1회 측정이고 표본이 작아서, v1과의 차이(4개)가 노이즈 범위 안일 수 있음
- 결론: **질문 문구만으로는 한계가 있음.** 진열대 전후 비교(상품이 실제로 사라졌나) 같은 다른 근거와 결합해야 함 (`decisions/001_진열대_전후_비교를_판정_근거로_사용.md`를 뒷받침하는 자료)

## 한계
