# 0단계 직접 촬영 목록 (putting_in_bag 집중 테스트)

## 목적
- 무료 사진에는 "상품을 가방·주머니에 넣는" 장면이 1장뿐이었음
- 직접 찍은 영상에서 프레임을 뽑아 Jev가 "넣음 / 안 넣음"을 구분하는지 확인함
- 결과는 `2026-10-28_jev_사진_테스트.md`와 같은 형식으로 남김

## 촬영 방법
- **구도**: CCTV처럼 **높은 곳에서 비스듬히 내려다봄**
  - 휴대폰을 선반 위나 삼각대에 고정하고, 머리보다 높게 둠
  - 손과 상품, 가방이 잘 보여야 함
- **얼굴**: 화면에 나오지 않게 함 (어깨 아래만 나오거나 뒤에서 찍음)
- **장소**: 집도 괜찮음
  - 선반이나 책상에 과자·음료 같은 상품을 진열대처럼 놓음
  - 모든 영상에서 배경과 카메라 위치를 같게 유지함
- **영상**: 가로 화면, 장면 하나당 10~20초, 1080p면 충분함
- **파일명**: 아래 표의 코드 그대로 사용 (예: `P1.mp4`)
- **저장 위치**: `docs/test-data/videos/` (커밋되지 않음)

## 장면 목록

### 넣음 (정답: putting_in_bag = 예)
| 코드 | 장면 |
|---|---|
| P1 | 진열대에서 상품을 집어 **에코백·가방에** 넣고 자리를 떠남 |
| P2 | 진열대에서 상품을 집어 **바지나 외투 주머니에** 넣음 |
| P3 | 진열대에서 상품을 집어 **옷 안이나 소매 속으로** 숨김 |

### 안 넣음 (정답: putting_in_bag = 아니오)
| 코드 | 장면 |
|---|---|
| N1 | 상품을 집어 살펴본 뒤 **다시 진열대에 놓음** |
| N2 | 상품을 **손에 든 채로** 화면 밖(계산대 쪽)으로 걸어감 |
| N3 | 카드나 휴대폰을 결제 단말기 대신 놓은 상자에 대는 **결제 동작** |
| N4 | **자기 가방에서 자기 물건**(휴대폰, 지갑)을 꺼냄 |
| N5 | **자기 물건**(휴대폰)을 **자기 가방에 다시 넣음** ← P1과 겉보기에 가장 비슷한 장면 |
| N6 | 사람 없이 진열대만 10초 |

- N4, N5는 "매장 상품인가, 손님 물건인가"를 Jev가 사진 한 장으로 구분할 수 있는지 보는 장면임 (handoff.md 13장 참고)

## AI 영상 생성 프롬프트 (직접 촬영이 어려울 때)
P1 결과를 보고 고친 점:
- 앞 10초가 빈 화면이었음 → 처음부터 손님이 진열대 앞에 서 있게 함
- 뒤에서 찍혀 손이 가려졌음 → 손님 옆모습이 보이고 가방이 카메라 쪽에 오게 함
- 가방이 두 개로 보였음 → 가방은 정확히 하나라고 적음
- 길이 → 장면마다 필요한 만큼만 (4~8초)
- 상품을 가져가도 진열대 모습이 그대로였음 (AI 영상의 한계) → 눈에 띄는 상품 하나를 정해 두고, 가져가면 그 자리가 **비어 보이게** 명시함
- 진열대 전후 비교용 → 영상의 처음 1초와 마지막 1초에는 사람이 진열대를 가리지 않게 함
