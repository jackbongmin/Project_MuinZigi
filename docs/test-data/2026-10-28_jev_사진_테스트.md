# 2026-10-28 Jev 사진 판단 테스트 (0단계)

## 목적
- 녹화본은 결국 프레임(정지 사진)으로 잘라 Jev에 보냄. 그래서 영상 처리를 만들기 전에 "Jev가 매장 사진 한 장을 보고 행동을 알아보는가"를 먼저 확인함
- 0단계 완료 기준: 사진 몇 장에 대한 Jev 판단이 실제와 대체로 맞음

## 조건
| 항목 | 값 |
|---|---|
| 모델 | `jev-1.14.0` (응답의 model 값으로 확인) |
| 전송 방식 | base64 JSON, 이미지 1장 + 질문 4개를 한 요청에 보냄 |
| 이미지 | Unsplash 무료 사진 8장, 가로 1,024px JPEG로 받음 |
| 판정 기준 | "예" 확률 0.5 이상이면 예 |
| 실행 | `./gradlew jevTest --tests '*JevPhotoLiveTest'` |
| 코드 | `backend/src/test/java/com/mujinjigi/domain/analysis/jev/JevPhotoLiveTest.java` |

### 질문 세트 v0
TypeSafe 권고대로 복잡한 질문 하나 대신 단순한 예/아니오(Noul) 질문으로 나눔.

| 이름 | 질문 |
|---|---|
| person | Is there a person or part of a person (such as a hand) in the image `photo`? |
| holding_product | Is a person holding a store product (not a shopping bag) in their hand in the image `photo`? |
| putting_in_bag | Is a person putting an item into a bag or pocket in the image `photo`? |
| paying | Is a person paying (by card, phone or cash) at a checkout or payment terminal in the image `photo`? |

## 해석
- **잘한 것**
  - 사람 유무, 상품을 손에 듦, 결제 중을 대부분 맞힘
  - 사람이 없는 통로(5번)는 person 0.33으로 "아니오"로 맞힘. 다만 다른 사진의 0.99보다 확신이 낮음
- **틀린 것**
  - 6번에서 바나나를 들고 있는데 holding_product는 0.39로 "아니오"라고 함
  - 질문에 "store product (not a shopping bag)"라고 적어서, 야외에서 봉지와 함께 든 바나나를 "매장 상품"으로 보지 않았을 가능성이 있음
  - 질문 문구에 민감하다는 뜻이라, 1단계에서 문구를 고치고 다시 측정할 대상임
- **확인하지 못한 것 (가장 중요)**
  - 이 서비스의 핵심 질문인 putting_in_bag에 "예"가 정답인 사진이 1장(6번)뿐임
  - 그 1장도 매장이 아니라 야외 사진임. 0.73으로 맞혔지만 1장으로는 판단할 수 없음
  - 무료 사진 사이트에는 "매장 안에서 상품을 가방·주머니에 넣는" 장면이 거의 없었음. 대부분 유료(Unsplash+)였음
- **CCTV와의 차이**
  - 1~7번은 사람 눈높이에서 가까이 찍은 사진임
  - CCTV처럼 위에서 넓게 찍은 사진은 8번 하나뿐이고, 사람이 작게 나와서 애매함이 커짐
  - 실제 프레임에서는 정확도가 더 낮을 수 있음

## 결론과 다음 할 일
- 사진 한 장으로 "사람이 있는가 / 상품을 들었는가 / 결제 중인가"를 판단하는 것은 쓸 만함
- 핵심인 "넣는 동작"은 아직 판단 근거가 부족함 → **0단계 완료 기준은 아직 통과로 보지 않음**
- 다음: 직접 연출한 사진으로 putting_in_bag을 집중 테스트함
  - 위에서 내려다본 구도, 매장과 비슷한 배경
  - "넣음"과 "안 넣음" 짝 사진: 들고만 있음 / 가방에 넣는 중 / 주머니에 넣는 중 / 장바구니에 담음
- 참고: 입력 토큰이 픽셀 수에 비례함 → 1단계에서 프레임 크기를 줄이면 비용을 줄일 수 있음 (포트폴리오 성능 기록 후보)
