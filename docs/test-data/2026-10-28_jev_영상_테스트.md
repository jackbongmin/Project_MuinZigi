## 추가 테스트: 진열대 전후 비교
### 왜 하는가
- P1처럼 가방에 넣는 순간이 가려지면 행동 판단만으로는 놓침
- 손님이 들어오기 전과 나간 뒤의 진열대를 비교해 "상품이 사라졌나"를 보면, 손이 가려져도 증거가 남음
- 이 방식이 되면 최종 판정 기준을 "진열대에서 사라진 상품 vs 결제 내역"으로 둘 수 있음

### 데이터
- before: P1 0초 프레임 (사람 없음)
- after: P1 19초 프레임 (사람이 나간 뒤)
- 확인 결과 두 프레임의 차이 이미지가 거의 단색이었음
  - AI가 손님이 상품을 가져가는 장면은 만들었지만, 진열대에서 그 상품이 빠진 모습까지는 그리지 않았음
  - 그래서 이 쌍의 정답은 "사라진 것 없음"임
- 사라진 경우를 시험하려고 **19초 프레임을 직접 수정한 사진**을 만듦
  - FFmpeg `delogo`로 윗칸 파란 과자 봉지 2개 자리를 지움 → `P1_after_edited.jpg`
  - 깔끔하게 지워지지 않고 흐린 조각이 남음. Jev가 "상품이 빠짐"이 아니라 "흐림"에 반응했을 수도 있음

### 조건
- 이미지 2장(`before`, `after`)을 한 요청에 보냄 (`JevClient.askYesNo(Map<String, byte[]>, ...)`)
- 질문
  - missing: Compared with the shelf in image `before`, is any product missing from the shelf in image `after`?
  - same: Do the shelves in images `before` and `after` look the same, with no products added, removed or moved?
- 실행: `./gradlew jevTest --tests '*JevShelfLiveTest'`

### 결과
| 비교 | 정답 | missing | same | 입력 토큰 |
|---|---|---|---|---|
| 같은 사진 두 장 (기준선) | 사라짐 없음 | N 0.10 ✅ | Y 0.96 ✅ | 5,126 |
| 0초 vs 19초 (실제 영상) | 사라짐 없음 | N 0.23 ✅ | Y 0.68 ✅ | 5,126 |
| 0초 vs 19초 수정본 (봉지 2개 지움) | 사라짐 있음 | Y **0.58** ✅ | N 0.21 ✅ | 5,126 |

- 6개 판단이 모두 정답과 일치함
- 하지만 "사라짐 있음"의 missing이 0.58로 기준선 0.5에 가까움. 확신이 약함
- 0초 vs 19초는 실제로 바뀐 게 없는데도 same이 0.68로, 같은 사진(0.96)보다 낮음. 영상 압축 때문에 생긴 미세한 차이에도 흔들림

### 해석
- 진열대 전후 비교는 **방향은 맞지만 지금 상태로는 약함**
- 원인 추정: 화면 전체(1280x720)를 비교해서, 봉지 2개는 화면의 아주 작은 부분임
- 개선 방향
  - 진열대 칸 영역만 잘라서(ROI) 비교하면 사라진 상품이 화면에서 차지하는 비율이 커짐 → missing 확률이 올라가는지 전후 측정 (포트폴리오 기록 후보)
  - 수정 흔적 없이 상품이 실제로 빠진 사진이 필요함 → 직접 촬영이나 진열대 변화가 있는 생성 영상
